## 🚀 Quick Fix (5 Minutes)

### Option 1: Just Want to See It Work?

1. **Download ANY GLB model** from:
   - https://github.com/KhronosGroup/glTF-Sample-Models/tree/master/2.0/Duck/glTF-Binary/Duck.glb
   - Or search "free glb model download"

2. **Save it to**: `backend/local_models/test.glb`

3. **Refresh your browser** and try uploading images again

4. **You should see the 3D model!** (even with 0% match, it will show the model)

### Option 2: Want Proper AI Matching?

1. **Add 3D models**: Place GLB files in `backend/local_models/`

2. **Add reference images**: Place glasses photos in `backend/reference_images/`
   - Name them same as models: `model1.glb` → `model1.jpg`

3. **Install Python dependencies**:
   ```bash
   pip install torch torchvision pillow
   ```

4. **Build embeddings**:
   ```bash
   cd backend
   python match.py --build
   ```

5. **Test again!**

## 🎨 Where to Get Free 3D Models

### Glasses/Eyewear:
1. **Sketchfab** (best quality)
   - https://sketchfab.com/search?q=glasses&type=models
   - Filter by "Downloadable"
   - Download as GLB format

2. **Free3D**
   - https://free3d.com/3d-models/glasses
   - Look for GLB or GLTF format

3. **TurboSquid Free**
   - https://www.turbosquid.com/Search/3D-Models/free/glasses

- https://github.com/KhronosGroup/glTF-Sample-Models
- Download any .glb file to test the viewer

## 🐛 Common Issues

### Issue: "No models found" in admin panel
**Solution**: Add .glb files to `backend/local_models/`

### Issue: "0% Match"
**Solution**: This is normal without reference images. The app will still show a model if one exists.

### Issue: Blank 3D viewer
**Solution**: 
1. Check browser console (F12) for errors
2. Verify GLB file is valid
3. Try a different model
4. Check model URL in network tab

### Issue: Python errors
**Solution**: 
```bash
pip install torch torchvision pillow
```
